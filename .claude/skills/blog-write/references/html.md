# HTML 쓰기와 HTML·Markdown 문서 옮기기

블로그 글 파일은 언제나 `src/content/blog/<slug>/index.md` 다. HTML 은 **그 안에 블록으로** 넣는다. 별도 `.html` 페이지는 만들지 않는다(메뉴·목록·RSS 에 안 잡히고 디자인을 우회한다).

`npm run check:posts` 가 아래 금지 항목을 **빌드 오류**로 막는다.

## 1. 허용 · 금지

| 구분 | 태그·속성 | 비고 |
| --- | --- | --- |
| ✅ 권장 | `<details>` `<summary>` | 접기. 안쪽 마크다운은 **앞뒤 빈 줄**이 있어야 렌더된다 |
| ✅ 권장 | `<figure>` `<figcaption>` | 캡션 있는 이미지. `<img>` 에 `alt` 필수 |
| ✅ 권장 | `<kbd>` `<sub>` `<sup>` `<mark>` `<abbr title>` | 단축키, 화학식, 강조, 약어 |
| ✅ 허용 | `<table>` + `colspan` `rowspan` | 마크다운 표로 안 되는 병합 표만 |
| ✅ 허용 | `<br>` | 표 칸 안 줄바꿈 정도만 |
| ⚠ 무의미 | `class` · `id` 속성 | 본문용 스타일이 없어 효과가 없다 (경고) |
| ✖ 금지 | `style` 속성 | 디자인 토큰을 우회한다 |
| ✖ 금지 | `<script>` `<iframe>` `<style>` `<form>` `<object>` `<embed>` `<link>` `<meta>` `<base>` | 공개 블로그 보안 |
| ✖ 금지 | `on…=` 이벤트 속성, `javascript:` 링크 | 보안 |

**마크다운으로 되는 것은 마크다운으로 쓴다** — 제목, 문단, 목록, 굵게, 링크, 인용, 코드, 단순 표, 이미지.

코드 예시로 HTML 을 보여 주고 싶으면 코드 블록(```html)에 넣는다. 코드 블록 안은 검사하지 않는다.

## 2. HTML 문서를 블로그 글로 옮기는 순서

노션·Confluence·Google Docs 내보내기, 직접 만든 HTML 페이지 등.

1. **본문만 가져온다.** `<head>`, 내비게이션, 푸터, 사이드바는 버린다.
2. **제목**: 문서의 `<title>` 또는 첫 `<h1>` → frontmatter `title`. 본문에서는 지운다.
3. **제목 단계를 한 칸씩 내린다**: `<h2>` → `##`, `<h3>` → `###`. 본문에 `#` 을 남기지 않는다.
4. **마크다운으로 바꾼다**: `<p>` `<strong>` `<em>` `<a>` `<ul>/<ol>` `<blockquote>` `<pre><code>` `<img>` 와 단순 `<table>`.
   - `<pre><code class="language-kotlin">` → ```kotlin 블록
   - 병합 셀이 있는 표만 HTML 로 남기고 `class`·`style` 을 지운다.
5. **모양 관련은 모두 지운다**: `style` · `class` · `<font>` · `<span>` 색·크기, `<center>`, 빈 `<div>` 래퍼, `&nbsp;` 여러 개.
6. **이미지**: 외부 URL 이미지는 가능하면 파일로 받아 글 폴더에 넣고 `./파일명` 으로 바꾼다(외부 링크는 언젠가 깨진다). `alt` 가 없으면 내용을 보고 설명을 쓴다.
7. **내보내기 흔적 정리**: 노션 ID 가 붙은 파일명, 추적 파라미터(`?utm_…`), 사내 문서 링크는 지우거나 공개 링크로 바꾼다.
8. **공개 금지 정보 점검**: 사내 주소·계정·고객 데이터가 있으면 옮기지 않고, 뺀 목록을 사용자에게 보고한다.
9. `npm run check:posts -- <slug>` 로 검사한다.

## 3. Markdown 문서를 옮길 때

- 기존 frontmatter 는 블로그 스키마로 바꾼다(`title` `description` `pubDate` `category` `platform` `tags` `draft`). 모르는 필드는 지운다.
- 옵시디언·위키 문법(`[[링크]]`, `![[이미지]]`, `> [!note]`)은 일반 마크다운으로 바꾼다.
  - `[[다른 글]]` → 블로그에 있는 글이면 `[제목](../slug/)`, 없으면 일반 텍스트
  - `> [!note] 내용` → `> **참고** 내용`
- 이미지 경로를 글 폴더 기준 `./파일명` 으로 맞춘다.

## 4. `.mdx` 가 필요할 때

본문에 Astro 컴포넌트를 넣어야 할 때만 `index.md` → `index.mdx` 로 바꾼다. 새 컴포넌트를 만드는 일은 디자인 변경이므로 사용자·관리자와 먼저 합의한다.
