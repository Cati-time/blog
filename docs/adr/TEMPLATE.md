## Context — 발단 (MUST)
무엇이 문제로 **드러났나**. 반드시 **증거**를 적는다 — 관찰·실행 결과·실패 사례·수치.
> 추측/일반론 금지. "왜 지금 이걸 정해야 하나"가 읽는 사람에게 보여야 한다.
